【Hack4Good 技术向善】乡课：给乡村教师的 AI 备课与全国教研共享工具

## 帖子正文

### 一、自我介绍

大家好，我是「乡课」项目的开发者。这个项目从最初的需求拆解、产品设计，到前后端实现、功能回归测试和公网部署，全程使用 Qoder 完成。

我关注的问题是：乡村教师的时间被备课大量挤占，而通用 AI 生成的教案往往默认「有投影、有教具、有完整课时」，老师拿到后还要二次改。乡课想把「学校真实有什么」变成生成教案的一等条件，并让一位老师的备课成为更多老师可以直接复用的公共资源。

---

### 二、我的作品是什么

乡课是给乡村小规模学校教师使用的 AI 备课与全国教研共享工具：把无投影、无教具、复式班等真实条件写进教案，支持复习课配套试题、按课题生成的 PPT，以及按课时编排的「闯关式」课件（含 JSON 课件与无投影单文件 HTML 课件），让一位老师的备课变成全国教师可复用的资源。

---

### 三、为什么做

- 乡村教师常常一人教多门课、跨 2–3 个年级，日均 4–6 节课，备课只能挪到晚上。
- 通用 AI 写教案默认理想教室，生成后还要老师把「投影演示」改成「粉笔 + 板书 + 口述」，省下来的时间又被改教案吃掉。
- 名师教案和精品课集中在城市名校与城区教研平台，村小既没有账号，也没有适配的学情。
- 县里的教研活动一学期几次，听完就散，优秀做法停留在个人电脑里，老教师退休经验容易断档。
- 学生端会增加屏幕时间、设备监管和错误讲解的风险；教师端杠杆更高：一位老师的一节课，直接影响几十个学生。因此乡课坚持「学生不进产品」。

---

### 四、怎么用（5 步以内）

1. 打开作品链接 https://xiangke-twfryk5inyt.qoder.zone ，选择「教师」身份，填写姓名与省份 / 县域（无密码）；登录后首页会带上本校默认条件。
2. 点「智能备课」，选择新授课或复习课，再选教材版本、年级、学科与课题；复习课需要填写知识区间。
3. 勾选本校乡村条件；按需打开「配套试题」（设置难度、题数、题型与知识区间）和「配套 PPT」（按课题自动编排）。
4. 生成教案包：查看无多媒体教学过程、板书设计、分层提问和三层作业；可评分、打印；配套 PPT 可全屏演示或导出 `.pptx`；首页「课件」入口还能按「第几 / 共几课时」生成逐页教学流程课件，无投影时一键打开单文件 HTML 课件。教案生成后即时公开为「教师原创」，无需审批。
5. 到「全国资源库」按来源、省份、课型、学科、年级筛选，一键复用并改编，查看完整改编链；在「我的」切换教研员身份，可在「教师教案」查看全平台教师教案；「拍照讲评」可把学生作业生成 10 分钟讲评稿和补救练习。

### 五、用 Qoder 做出来的过程

#### 1. 需求拆解

我把《乡课》项目方案交给 Qoder，让它整理用户角色、赛道契合度、P0 功能、数据模型与演示链路。我们共同确定了三个边界：

- 只做教师端，不做学生端、家长端；
- 教案必须是结构化、可打印的教案包，而不是聊天记录；
- 先用本地可演示的生成引擎跑通闭环，再在正式版接入大模型与云开发。

#### 2. 交给 Qoder 的部分

- 初始化 React + TypeScript + Vite + Tailwind 项目，搭建移动端小程序形态的应用外壳和「纸与田野」视觉系统；
- 生成首页、智能备课、教案包详情、全国资源库、拍照讲评、我的、教师教案、全国统计、关于等页面；
- 实现乡村约束适配引擎：无设备 / 仅电视 / 有白板、无教具 / 可自备 / 有限教具箱、复式班 / 小班 / 大班、30 / 40 分钟、三层学情；
- 生成结构化教案包：教学目标、重难点、无多媒体教学过程、板书、分层提问、三层作业、教具替代、课后反思；
- 加入复习课模板、试题生成器（难度、题数、题型、知识区间）与按课题生成的 PPT（含全屏演示和 `pptxgenjs` 导出 `.pptx`）；
- 实现「按课时」的课件引擎：课时边界、核心活动、环节时间、每页固定字段与输出自检；支持 JSON 课件在线修改与容错应用、无投影单文件 HTML 课件（键盘翻页、板书卡、按 N 显示教师备注），并按配图词检索开放素材；
- 完成全国资源库、教师原创即时公开、教研员只读查看、复用改编链、语音速填、拍照讲评、县域/全国统计；
- 用 Qoder Sites 构建、预览、发布并开放公网访问。

#### 3. 我改了什么

Qoder 给的是可运行的首版，我随后按演示反馈做了多轮产品调整：

- 把「县本资源」升级为「全国资源库」，加入省份筛选与全国统计，资源覆盖 9 个省份、12 所学校；
- 取消教案审批：教师生成即公开为「教师原创」，教研员只查看、不设通过 / 退回；
- 把配套 PPT 从「复述教案结构」改为「按课题独立编排」：学习目标、情境导入、知识点、例题、练习、小结、课后任务；
- 用 Qoder 浏览器逐项回归备课、复习课、试题、PPTX 导出、资源库筛选、复用、讲评和统计，修复了教师教案计数、课题推荐选中态、复习课重复点击、资料标签、复用课件作者归属等问题。

### 六、演示与数据说明

- 本演示的 AI 生成为本地规则引擎，不调用外部大模型；生成内容为精编与模板内容。
- 数据保存在浏览器本机，不上传服务器；截图中的学校、师生和统计均为虚构示例数据，公开站点初始为空白，登录并生成后即可得到同样的教案、试题与课件结构。
- 正式版将迁移微信小程序 + 云开发，接入大模型结构化输出、微信内容安全与作业图片脱敏。
- 项目不向教师收费，正式落地走县域教育局采购 + 公益基金会资助。
