# 乡课 · 教师 AI 备课与全国教研共享

> 面向乡村教师的移动端 Web 应用，模拟微信小程序教师端的完整链路。
>
> **在线体验**：https://xiangke-twfryk5inyt.qoder.zone

**一句话**：乡课把「学校没有投影仪」写进教案，把一位老师的备课变成全国教师的公共资源。

---

## 1. 给谁用

- **教师**：一人教多门课、跨年级任教，备课时间被挤压；乡村教师的无设备、无教具条件同样是一等输入。
- **全国教研员**：查看全平台教师与教研员生成的教案，组织跨区域教研。
- **中心校 / 教育局管理者**：查看备课覆盖率与资源复用情况。

**学生不进入产品**：不收集学生账号、不使用学生人脸与姓名，避免屏幕时间与错误讲解风险。

## 2. 三个记忆点

1. **没有投影也能上的教案**：多媒体、教具、班级规模、课时长度、学情基础都是生成的一等输入。
2. **一位老师的备课变成全国的公共资源**：AI 生成 → 教师原创即时公开（无需审批）→ 全国资源库 → 一键复用与改编；教研员可查看全平台教师教案。每份资源仍标注省份与县域来源。
3. **学生不碰屏幕**：面向教师，用教师杠杆撬动教育公平。

## 3. P0 功能（均可在演示中跑通）

| 模块 | 说明 |
| --- | --- |
| 智能备课 | 选教材 / 年级（一至九年级）/ 学科 / 课题 + 勾选乡村条件，生成结构化教案包；支持新授课与复习课 |
| 教案包 | 教学目标、重难点、无多媒体教学过程、板书设计、分层提问、三层作业、教具替代、反思提示；支持打印 |
| 复习课与试题 | 复习课按知识网络、典型例题、错题讲评组织；可选生成 5–15 道配套试题，设置难度、题数、题型与知识区间，含答案解析；勾选配套 PPT 时，试题自动排入「课中练题」页，答案与解析只写入讲者备注 |
| 课件生成 | 按课时生成教学流程：教材版本、年级、册次、课题、第几 / 共几课时、35 / 40 分钟、课型、学情与教具为必填设定。引擎按「课时边界 → 核心活动 → 环节时间 → 每页固定字段 → 自检」五步编排；每页含学生做什么、教师问什么、学生得出、教师备注、配图建议；输出前自检：课时边界、时间加总、屏幕正文 ≤ 3 行、每页 1 个问题、图 / 活动指令、答案只在讲者备注、无教案词残留、练习答案与互评。课件按「闯关」组织环节，每页固定为标题区、图解区（具体到图形 / 颜色 / 数量）、做一做、想一想、说一说、口诀 / 板书，支持全屏演示与导出 .pptx（服务端 python-pptx 渲染） |
| JSON 课件 | 课件页右上角入口：按「年级 + 课题」用本地模板生成标准 JSON（cover / graphic / summary）；红绿圆点与树状图用 SVG 渲染，算式用 KaTeX 渲染；JSON 可在线修改并容错应用，自动存入 localStorage；pptxgenjs 一键导出，文字、图形与教师备注与预览一致。当前未接 AI，预留 JSON 契约。 |
| 课件输出分支 | 教案详情按设备条件给出输出建议：有投影走「课堂时间轴 + PPT 精简课件」，每个教学环节标注对应课件页码（看课件 · 第 X–Y 页），保证教案与课件一一对应；无投影 / 低设备 / 低带宽可一键下载或打开「单文件 HTML 课件」，支持键盘翻页、板书卡、按 N 显示教师备注，无外部依赖；复式班双泳道分支保留入口，待后续补充。 |
| 全国资源库 | 按来源 / 省份 / 学科 / 年级 / 学校筛选与搜索；全国认证与教师原创标识；复用次数与评分 |
| 改编复用 | 一键复用生成副本，记录来源教案 ID、改编说明，形成可追溯的改编链 |
| 拍照讲评 | 拍 / 传作业 → 题目与作答识别 → 错因分布 → 10 分钟讲评稿与补救练习 |
| 教师教案 | 教研员之间、教师与教研员之间可互相查看已生成教案（含原创、私有与全国认证）；无需审批，不设通过 / 退回 |
| 全国统计 | 覆盖省份、学校与教师、复用率、学科 × 年级覆盖、高频错点、受益学生数 |
| 外部资源 | 接入国家中小学智慧教育平台、人教社、国家教育资源公共服务平台、B 站教学视频、Openverse / Wikimedia 配图；按课题一键跳转检索，免登录、无需 API 密钥 |

另含：语音速填（自然语言解析）、教师成长档案、一键纠错、评分、打印版教案。

## 4. 体验路径（约 4 分钟）

1. 首页 →「给明天备一堂能上的课」。
2. 选三年级数学《分数的初步认识》，勾选「无设备 / 无教具 / 复式班」，生成教案包。
3. 查看「乡村适配」说明、无投影教学过程、板书设计、三层作业。
4. 返回首页 →「课件」：选定册次与第几课时（第 1 课时只讲几分之一，第 2 课时讲几分之几与同分母比较）、40 分钟、新授课与教具，生成后按页查看固定字段，可全屏演示或导出 .pptx。
5. 切换到「复习课」，填写知识区间，勾选配套试题并设置难度 / 题数 / 题型，并可勾选生成配套 PPT。
6. 生成后自动以「教师原创」公开，无需审批；退出登录后以**教研员**身份进入，可在「教师教案」查看全平台教师教案。
7. 回资源库打开《秋天的雨》→ 复用并改编（按本校条件重新适配）→ 查看改编链。
8. 拍照讲评 → 用示例作业 → 开始识别 → 查看错因分布、10 分钟讲评稿、补救练习。
9. 我的 → 成长档案 / 全国统计 / 关于乡课。

> 教师 / 教研员身份在登录页选择，登录后固定，需退出登录才能切换。

## 5. 乡村约束建模

| 约束维度 | 可选值 | 对生成结果的影响 |
| --- | --- | --- |
| 多媒体条件 | 无设备 / 仅电视 / 有白板 | 无设备时全课改为板书 + 纸笔 + 口述；电视只播放一次关键画面 |
| 教具条件 | 无 / 可自备 / 有限教具箱 | 给出纸条、瓶盖、玉米粒、玻璃瓶等生活化替代 |
| 班级规模 | 复式班 / 小班 / 大班 | 复式班插入「先布置、后讲授、再回流」环节与分年级任务单 |
| 课时长度 | 40 / 30 分钟 | 按目标课时等比重排环节时长，保留核心探究与当堂反馈 |
| 学情基础 | 待补基础 / 正常 / 学有余力 | 增加旧知复习或拓展任务，作业按三层给出 |

## 6. 技术与数据说明

- **栈**：React 19 + TypeScript + Vite + Tailwind CSS，静态构建输出到 `dist/`。
- **路由**：Hash 路由，天然适配静态托管。
- **状态**：React Context + `localStorage`（键：`xiangke.state.v1`），刷新不丢数据。
- **登录**：先在登录页选择「教师 / 教研员」身份，再填姓名 + 省份 + 县域，无密码；可勾选「记住登录信息」，下次登录自动填入姓名、身份与地区。县域覆盖 34 个省级行政区下约 3000 个县级行政区（区 / 县 / 县级市 / 旗），支持「其他」手动填写。身份登录后固定，需退出登录才能切换；全站只显示姓名与「省份 · 县域」，不展示学校名称。
- **生成**：`src/lib/lessonContent.ts` 精编教案 + `src/lib/engine.ts` 乡村约束适配与学科模板，教案默认不调用外部模型；课件可选择调用 DeepSeek 生成课件结构，未配置或调用失败时自动回退本地规则。
- **讲评**：`src/lib/scan.ts` 示例识别结果，上传图片只在本地预览、不写入存储。
- **课件**：`src/pages/Courseware.tsx` 提供独立课件入口；`src/lib/pptEngine.ts` 是课时教学设计引擎，按教材 / 年级 / 册次 / 课题 / 课时 / 时长 / 课型 / 学情 / 教具生成一节课的教学流程（先定课时边界，再定核心活动、环节时间与每页固定字段，并自动自检）。导出 .pptx 时优先调用 `server/app.py`（python-pptx，基于模板或从零构建），服务不可用时自动回退到本地 `pptxgenjs`。
- **外部资源**：`server/oer.py` 聚合开放资源，并优先使用 `server/data/oer_index.json` 本地预取索引，站内检索毫秒级返回。`npm run oer:crawl` 会通过百度图片（Bing 兜底）检索全网课堂素材，按标题关键词过滤后下载、压缩为 JPEG 存入 `server/assets/oer`；课件图解区的每一页会先解析该页「配图要求」里的图形、实物与动作词（如圆形、月饼、数轴、涂色、平均分），按「课题 + 年级 + 配图词」检索并排序，本地没有贴合素材时即时联网抓取一次并缓存，再按页面标题稳定轮换。网页全屏预览与导出的 PPTX 使用同一张图，讲者备注标注素材标题与来源站点。外部不可达时回退到内置图示（1/4 圆图、3/5 长条、10 的分成、数轴）。
- **配图方案**：图解区按配图要求自动生成四类可直接使用的产物：树状图 / 逻辑关系输出 Mermaid 代码；几何图形与数量对应输出可运行的 python-pptx 代码；情境小动物、食物输出中英文 AI 绘画提示词；简单排版输出形状、颜色、尺寸、行列数等 PPT 操作参数。方案可在全屏预览中展开复制，并写入 PPT 讲者备注；几何图形与树状图会在导出的 PPTX 中直接绘制为原生形状。

### 可选：接入 DeepSeek 生成课件

课件页点击「生成」时，后端会先调用 `POST /api/ppt/generate`，由 DeepSeek 生成课件结构 JSON，再交给 python-pptx 渲染；未配置 Key、接口超时或返回内容不合法时，前端自动回退到本地规则生成，不影响使用。

```bash
# Windows PowerShell
$env:DEEPSEEK_API_KEY = "sk-..."
$env:DEEPSEEK_BASE_URL = "https://api.deepseek.com"   # 可选
$env:DEEPSEEK_MODEL = "deepseek-chat"                 # 可选
python server/app.py
```

- 健康检查 `GET /api/ppt/health` 中的 `ai` 字段表示是否已启用 DeepSeek。
- API Key 只保存在后端环境变量中，不会下发到浏览器。
- 未配置 Key 时 `/api/ppt/generate` 返回 503 `ai_not_configured`，前端直接走本地生成。
- **数据**：初始不含演示数据；支持全国 34 个省级行政区与一至九年级，教案、课件、讲评与统计均来自本机使用，可在「我的 → 清空本机数据」清除。
- **正式版路线**：微信小程序（原生）+ 云开发 / 云函数；大模型结构化输出、微信内容安全 `msgSecCheck`、图片姓名打码与 7 天自动删除。

## 7. 本地运行

```sh
npm ci
npm run dev      # http://127.0.0.1:5173
npm run dev:ppt  # python-pptx 导出服务 http://127.0.0.1:8001（另开一个终端）
npm run build    # 类型检查 + 构建到 dist/
npm run preview
```

Node 要求：`^22.13.0 || >=24.0.0`。PPT 服务需要 Python 3.9+ 与 `python-pptx`（`pip install python-pptx`）；把自定义母版放到 `server/templates/template.pptx` 即沿用其主题与母版（画布统一 16:9），没有模板时从零构建。

## 8. 目录

```text
src/

  lib/          # 类型、数据仓库、生成引擎、初始状态、讲评、解析、路由
  pages/        # 首页 / 备课 / 课件 / 教案包 / 资源库 / 讲评 / 我的 / 教师教案 / 统计 / 关于
  App.tsx       # 外壳与导航
  globals.css   # 「纸与田野」视觉系统（--site-* 变量可被设计工作台调节）
```

## 9. 边界与合规

- AI 生成内容标注来源；教师原创即时公开，教研员可查看并提出建议；全国认证是平台精选标识。
- 作业图片正式版上传即裁切题目、姓名打码，7 天自动删除，不进公共库。
- 教材版权：只引用目录结构，不复制教材正文。
- 可持续：面向区域教育局与公益基金会，**不向教师收费**。
